# Project Instructions

- This project uses bare React Native only.
- Never use Expo, Expo CLI, Expo packages, or Expo-managed workflows.
- Use React Native and Metro for the app and JavaScript bundling.
- Keep native integrations in the platform projects, with Android support implemented using the existing React Native Android project.
- Do not introduce a framework or tooling layer that replaces React Native or Metro.

## Git Publishing

- Do not commit or push changes unless the user explicitly asks to publish them.
- A direct request to set up or publish a change on GitHub authorizes creating a `codex/` branch, committing the requested changes, and pushing that branch. Do not ask for a second confirmation for those steps.
- A request to edit files in the workspace alone does not authorize committing or pushing them.
